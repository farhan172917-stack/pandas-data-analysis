
# Data Analysis Project Using Pandas

## Overview
A Python data analysis project that cleans a CSV dataset,
calculates summary statistics, groups sales data, and
generates a product revenue chart.

## Features
- CSV loading with Pandas
- Missing-value and duplicate handling
- Data filtering and grouping
- Revenue analysis by product, category, and city
- Summary statistics
- CSV exports and chart generation

## Technologies
- Python
- Pandas
- Matplotlib

## Installation
```bash
python3 -m venv venv
source venv/bin/activate
python -m pip install -r requirements.txt
```

## Run
```bash
python main.py
```

## Outputs
- cleaned_sales_data.csv
- product_sales_summary.csv
- sales_chart.png
